# Codveda Full-Stack Development Internship

Projects for the Codveda Technology Full-Stack Development internship. Each level has its own folder with its own README.

| Level            | Folder               | What I built                                                                                        |
| ---------------- | -------------------- | --------------------------------------------------------------------------------------------------- |
| 1 - Basic        | [level-1](./level-1) | Development environment setup, a REST API with Express, and a frontend in HTML, CSS, and JavaScript |
| 2 - Intermediate | [level-2](./level-2) | MongoDB integration with Mongoose, and JWT authentication with role-based access                    |
| 3 - Advanced     | [level-3](./level-3) | A deployed MERN app with authentication, roles, and real-time updates with Socket.io                |

**Live demo (Level 3):** https://codveda-fullstack-internship-zak.vercel.app

## Tech used

JavaScript, React, Node.js, Express, MongoDB (Mongoose), JWT, bcrypt, Socket.io, Axios, Git and GitHub, Vercel, Render, MongoDB Atlas
